# Chandel Family Invitation — polished edition

Static HTML/CSS/Vanilla JS site. Deploy the contents of this folder to the Vercel project root (Framework Preset: Other; Build and Install commands blank; Output Directory `.`).

## Assets
- `assets/griha-pravesh-entrance.png` — entrance photograph used in hero.
- Add `assets/lord-rama.jpg` for the divine image panel.
- Add `assets/devotional-flute.mp3` for optional instrumental audio.
- Add `og-invite.jpg` in the public root for rich social previews at the configured absolute OG URL.

## Editable ceremony timings
Search for `timePuja`, `timePath`, `timeHavan`, and `timeBhoj` in `upgrade.js`. They intentionally say “Timing to be announced” until you provide confirmed times; replace those labels in both language dictionaries.

## Notes
The calendar event is an all-day event covering March 10–11, 2027 in Lucknow. No map or directions integration is included. The canonical/share URL is the root domain.
